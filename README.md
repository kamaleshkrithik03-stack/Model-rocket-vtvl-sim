##What is this repo about and why i built it.
This repo contains a gamified simulator of an actual TVC rocket with somewhat of an accurate(maybe) simulation. It is more inetractive and lively than my previous versions.
I built it as a mirror om my real TVC rocket(on going in fabricate YSWS).

##what are the files
`Phase1.py`            First basic version – simple throttle and altitude which includes a nominal bg(better than my ASCII version though)
| `Phase2.py`          Added more flight behaviour and basic controls (and a moving bg)
| `Phase3.py`          Further improvements to physics and visuals (i included my phy engine from last repos)
| `Phase4.py`           More complete flight model with additional features 
| `Phase5.py`           **Final and best version** – full feature set (TVC, fuel, wind, COM/COP, parachute, scoring, etc.) 
| `Types_of_clouds.jpg`  Background image used in flight 
| `launch_real.JPG`      Menu  background image
