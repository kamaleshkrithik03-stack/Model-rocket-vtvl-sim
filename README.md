# What is this repo about and why i built it.
This repo contains a gamified simulator of an actual TVC rocket with somewhat of an accurate(maybe) simulation. It is more inetractive and lively than my previous versions.
I built it as a mirror om my real TVC rocket(on going in fabricate YSWS).

**Phase 5 is the final version(seen by the 600 lines of code).**  
(Note: Phase 5 may have appeared earlier under the name `karman_reusable_rocket`.)

---

## Features

- Throttle + TVC gimbal control
- Adjustable fuel, wind, and target apogee
- COM & COP sliders (stability margin)
- Wind + random gusts
- Parachute on descent(with a longer string to make sure it doesnt look hideous)
- Scoring based on apogee accuracy and landing precision
- Simple flight graph after landing
